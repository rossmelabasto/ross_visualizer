¿Va a funcionar en mi compu?

Este comando revisa tu sistema y te dice qué funciones van a andar. Solo lee: no instala nada, no pide contraseña y no envía datos a ningún lado. Córrelo desde una terminal de tu escritorio.

curl -fsSL https://ros.rossmel.com/check.sh | bash

¿Prefieres leerlo antes? Está en GitHub. Si algo sale mal, la salida se puede pegar tal cual en un issue.

Instalar

Agregas el repositorio una vez y las actualizaciones te llegan junto con las del resto de tu sistema.

Agregar el repositorio e instalar

curl -fsSL https://ros.rossmel.com/key.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key C08F57FCE06B95B52145012C274187B9D5E9FFEB
printf '\n[ross]\nServer = https://ros.rossmel.com/arch/x86_64\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu ross-visualizer-bin

Actualizar

sudo pacman -Syu

Desinstalar

sudo pacman -Rns ross-visualizer-bin

Si ya no lo quieres, borra también el bloque [ross] de /etc/pacman.conf.

Instalar con tu ayudante de AUR

paru -S ross-visualizer-bin

Con yay es igual: yay -S ross-visualizer-bin. Se actualiza cuando actualizas los paquetes de AUR.

Desinstalar

sudo pacman -Rns ross-visualizer-bin

Agregar el repositorio e instalar

curl -fsSL https://ros.rossmel.com/key.asc | sudo gpg --dearmor -o /usr/share/keyrings/ross.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/ross.gpg] https://ros.rossmel.com/apt stable main" | sudo tee /etc/apt/sources.list.d/ross.list
sudo apt update
sudo apt install ross-visualizer

Actualizar

sudo apt update && sudo apt upgrade

Desinstalar

sudo apt remove ross-visualizer
sudo rm /etc/apt/sources.list.d/ross.list /usr/share/keyrings/ross.gpg

Agregar el repositorio e instalar

sudo curl -fsSL https://ros.rossmel.com/rpm/ross.repo -o /etc/yum.repos.d/ross.repo
sudo dnf install ross-visualizer

La primera vez dnf te pregunta si confías en la clave. Su huella es C08F 57FC E06B 95B5 2145 012C 2741 87B9 D5E9 FFEB.

Actualizar

sudo dnf upgrade

Desinstalar

sudo dnf remove ross-visualizer
sudo rm /etc/yum.repos.d/ross.repo

Sin instalar nada

Descarga el AppImage de la versión @VERSION@, hazlo ejecutable y ábrelo. Sirve para cualquier distro, pero no se actualiza solo y tu sistema igual necesita pipewire y playerctl.

chmod +x ross_visualizer_@VERSION@_amd64.AppImage
./ross_visualizer_@VERSION@_amd64.AppImage

Requisitos

Las dependencias se instalan solas con cualquiera de los repositorios. Lo único que depende de tu sistema es esto:

FunciónQué necesita
La app y las escenasLinux x86_64 con glibc 2.35 o más nueva y una GPU con WebGL2
Reaccionar a la músicaPipeWire corriendo. PulseAudio solo no alcanza
Canción, portada y controlesUn reproductor con MPRIS: Spotify, un navegador y casi todos los de Linux
Overlay sobre las ventanasWayland con layer-shell: KDE Plasma, Hyprland, Sway, niri y otros. En GNOME o X11 tienes la pantalla completa, sin overlay
